# 실내 이상기후 모니터

`air_log.csv` 센서 로그로 실내 환경의 **현재 상태 · 과거 이력 · 추이**를 분석하고, 현재 위치의 **외부 날씨**와 비교하는 로컬 웹 대시보드입니다.

## 실행

```bash
python3 server.py            # → http://localhost:8000
python3 server.py --port 8080 --csv /path/to/air_log.csv
```

- 추가 설치 없음 (Python 3.8+ 표준 라이브러리만 사용)
- 차트 라이브러리(Chart.js)와 외부 날씨(Open-Meteo)를 인터넷에서 불러옵니다
- 센서가 CSV에 행을 계속 추가하면 새로 고침하지 않아도 5초마다 자동으로 반영됩니다

## 화면 구성

| 탭 | 내용 |
|---|---|
| 현재 | 지표별 현재 값과 상태(좋음/주의/위험), 경고 배너, 외부 날씨, 실내·외부 비교, 환기 권고, 최근 1시간 차트 |
| 과거 이력 | 기간 선택(1시간~전체/직접 지정), 지표별 시계열(평균 + 최소~최대 음영), 외부 기온·습도·PM2.5 겹쳐보기, 이상 구간 표시, 일자별 요약 |
| 추이 분석 | 선택한 구간의 선형 회귀로 구한 변화율, 30분 후 예측, 기준선 도달 예상 시간, 시간대별 평균 패턴, 실내·외부 기온 상관 분석 |
| 이상 이벤트 | 데이터 품질 요약, 환경 이상과 센서 이상 이벤트 목록(행을 클릭하면 해당 구간 차트로 이동), 탐지 기준 |

## 이상 탐지 방식 (`analysis.py`)

- **기준 이탈**: 1분 평균값이 `THRESHOLDS` 범위를 벗어난 경우 (CO₂ 1000/2000ppm, PM2.5 35/75µg/m³, 온도 18~26°C, 습도 30~60% 등)
- **급변**: 직전 60분의 중앙값과 MAD로 계산한 robust z-score가 5 이상인 경우
- **센서 이상**: AM 센서가 0.0°C / 99.0%를 출력하는 고장 패턴, 값이 장시간 그대로인 경우(CO₂ 60분, 온·습도 4시간), 5분 이상의 수신 공백

기준값은 `analysis.py` 위쪽의 `THRESHOLDS`와 `METRICS`에서 바꿀 수 있습니다.

## 외부 날씨

- 처음 접속하면 브라우저 위치 권한을 요청하고, 거부하면 서울을 기본 위치로 사용합니다. 도시 검색으로 위치를 바꿀 수 있습니다.
- [Open-Meteo](https://open-meteo.com) (API 키 불필요): 현재 날씨, 과거 시간별 기온·습도(최대 92일), 대기질(PM2.5)
- 위치 이름 조회: BigDataCloud reverse geocoding (실패하면 좌표로 표시)
