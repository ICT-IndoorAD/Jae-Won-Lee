    시간대별 평균 패턴

    실내 vs 외부 기온

    같은 시각(1시간 단위)의 외부 기온과 실내 온도(DHT)를 비교합니다.

    행을 클릭하면 해당 구간의 과거 이력 차트로 이동합니다.
